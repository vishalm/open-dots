# Open Dots marketing site

The public landing page for [Open Dots](../README.md) - a self-hosted,
open-source alternative to paid AI agent products. Next.js (App Router),
Tailwind CSS v4, a react-three-fiber hero visual, and next-themes for
light/dark mode.

Live at [open-dots-kappa.vercel.app](https://open-dots-kappa.vercel.app).

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run start
```

## Deploy

Linked to the `open-dots` Vercel project. Pushes to `main` on
[vishalm/open-dots](https://github.com/vishalm/open-dots) auto-deploy, or
deploy manually from this directory:

```bash
npx vercel --prod
```
